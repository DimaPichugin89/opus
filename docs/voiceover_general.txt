МАСЛАРАДА. ОБЩИЙ БЛОК. ТЕКСТ ОЗВУЧКИ
Темп спокойный, около 2 слов в секунду. Голос тёплый, без рекламного напора.
Паузы: «/» = короткая пауза (0,3 с), «//» = пауза между мыслями (0,8 с).
Ударения, где возможна ошибка: сыродАвленное, отжИм, льнянОе, масларАда.

--- СТОРИС 1. Что такое сыродавленное масло (≈15 с) ---
Что такое сыродавленное масло? //
Это семена, / которые просто давят прессом. / Не выше тридцати градусов / и без химии. //
Поэтому в масле остаётся всё, / что было в семенах: / вкус, / запах / и польза.

--- СТОРИС 2. Как делают обычное подсолнечное (≈20 с) ---
А как делают обычное подсолнечное масло с полки? //
Семена прогревают. / Остатки масла вытягивают растворителем. / Потом его очищают, / отбеливают / и пропаривают при двухстах градусах, / чтобы убрать запах. //
Получается масло без вкуса и запаха. / Но вместе с запахом уходит и часть пользы.

--- СТОРИС 3. А оливковое? (≈18 с) ---
А оливковое? / Хорошее Экстра Вирджин тоже отжимают без нагрева. //
Но омеги-три в нём почти нет, / а в льняном масле её больше половины. //
До полки оливковое едет и хранится месяцами. / А если на бутылке написано просто «Олив ойл», / внутри обычно смесь с рафинированным.

--- СТОРИС 4. Что даёт организму (≈18 с) ---
Что даёт сыродавленное масло? //
Витамин Е. / Он нужен коже / и защищает клетки. //
Омега-три и омега-шесть. / Организм не умеет делать их сам, / они приходят только с едой. //
Эти жиры нужны сердцу, / сосудам / и мозгу.

--- СТОРИС 5. Почему отжим под заказ (≈16 с) ---
Почему под заказ? //
Масларада отжимает масло только после заказа / и отправляет не позже чем через два дня. //
Дата отжима стоит на каждой бутылке. //
К вам приходит свежее масло, / а не то, что полгода стояло на складе.

--- СТОРИС 6. Как пользоваться (≈18 с) ---
Как пользоваться? / Одна-две ложки в день / в готовое блюдо: / салат, / кашу, / овощи / или творог. //
На сыродавленном масле не жарят: / от нагрева польза уходит. //
Храните бутылку в холодильнике. / Масло без глютена и лактозы.

--- СТОРИС 7. Линейка и заказ (≈18 с) ---
Девять масел: / подсолнечное, / льняное, / кунжутное, / тыквенное, / конопляное, / горчичное, / рыжиковое, / миндальное / и масло расторопши. / У каждого свой вкус / и своя польза. //
Выберите своё / и заказывайте на масларада точка ру. / Отжим под ваш заказ.
